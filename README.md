# steve-s-toolbelt
Unlimited saved hotbars for Creative: pages, groups, full-inventory presets, search, radial menu and text export/import. Client-side, Fabric 1.21.11. Безлимитные сохранённые хотбары для креатива: страницы, группы, пресеты инвентаря, поиск, радиальное меню и экспорт текстом. Только клиент, Fabric 1.21.11.
